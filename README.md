# ひだまりコミュニティ Webサイト

Discordサーバー向けの静的サイトです。HTML・CSS・JavaScriptのみで構成しているため、ビルドは不要です。

## ページ

- `index.html` — ホームと招待リンク概要
- `about.html` — サーバーの詳細紹介
- `links.html` — サイバーリンク、ホームページ、X
- `team.html` — 運営の6役職

## 公開前に変更する項目

1. `script.js` 冒頭の `siteLinks` に、Discord招待URL、サイバーリンクURL、XのURLを設定してください。未設定のリンクは「準備中」と表示され、クリックできません。
2. 「ひだまりコミュニティ」は仮のサーバー名です。実際の名称に合わせて各HTMLの見出し、タイトル、説明文を変更してください。
3. `team.html` の各「メンバー名」と紹介文を実際の担当者に合わせて変更してください。複数人いる役職は、同じ役職の `member-grid` 内に `member-card` を追加できます。
4. 必要に応じて、サーバー紹介文を実際の活動内容に合わせて変更してください。

`index.html` をブラウザーで開くか、静的ファイルを配信できる任意のサーバーで確認できます。外部フォントが読み込めない場合も、端末の日本語フォントで表示されます。
